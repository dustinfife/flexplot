## Explicit indirect fields and legacy restoration

- Dataset input: FP-03/1, LM-17/1, GLM-24/1, MM-20/1 require deterministic host
  data/schema checks; `data` is not an editable analysis control.
- LM-17 restores actual legacy output/label/interaction options and line/center
  compatibility through real protobuf. Generated main effects are observed after
  native initialization; comparisonMagnet is derived separately at LM-17/2 from
  actual binary outcome/categorical-x fitted data and native grouping capability.
- GLM-24/5–6 restores explicit and omitted legacy Gaussian selectors. Revision
  zero triggers the current output/label/interaction migration once. Steps 1/2/4
  inspect inferred family/outcome alongside Automatic selector, actual event coding,
  family/link specification and independent realized-data model estimates.
- MM-20 restores revision-zero shared layout, prediction, cluster count and arrays
  into current revision 2, preserving samplePolicyVersion and legacy includeCI.
  The next transition diverges settings and requires repeated host reopen without
  recopying. MM-04/3–4 changes legacy includeCI through protobuf restoration,
  never through a nonexistent checkbox; fixed-effect p remains hidden and Wald
  confidence intervals remain available.
- LM-16/2–3, GLM-23/2–3 and MM-19/2,11 commit actual generated label rows;
  inspect both retained stores, rendered text and survival through editor/output
  hiding and reopen. No hidden store is pretended to be user-editable.

MM-11 explicitly selects the comparison CAS mode and requires directional Model 2
into Model 1 ghost geometry. Existing Mixed comparison checkpoints now supply
comparison roles/mode/count independently instead of relying on the old shared
main settings. LM-15 uses the current ordinary grouping warning fallback.
MM-15 retains invalid-to-valid layouts with a valid other image and fitted tables;
only the invalid image may fail, with no stale image after recovery. The invalid
cluster cases explicitly put binary in panels: an empty saved panel list decodes
to NULL and legitimately auto-selects the cluster, so it cannot establish this
error. Comparison diagnostics say “shared grouping variable”; the protobuf replay
checks the actual text, intact tables and valid recovery.
